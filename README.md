# Secure Login System

## Project Description
This project is a Secure Login System developed in Python using the Tkinter library. It provides a graphical user interface (GUI) for user login.

## Features
- User login interface
- Username and password validation
- Message box notifications
- Simple and user-friendly GUI

## Requirements
- Python 3.x
- Tkinter (comes with Python)

## How to Run
1. Download the project.
2. Open a terminal in the project folder.
3. Run:

python design.py
